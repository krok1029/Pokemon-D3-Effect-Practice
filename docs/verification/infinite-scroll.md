# #19 圖鑑無限捲動驗收

日期：2026-09-19。使用者指定以 infinite scroll 實作分段瀏覽，並改善大量圖片載入與快速捲動。功能、圖片及虛擬化分別提交，沿用既有篩選、型態網址與返回契約。

## 實作

- 首頁面及 `GET /api/pokemon` 共用 `loadPokemonListPage`，每批 24 筆。先篩選與切片，再組裝卡片；不為整份資料計算或傳送詳細相剋。能力條仍使用全資料的最大值，型態筆數與排序不變。
- 接近底部 600px 自動載入下一批；提供手動載入、載入前 24 筆及錯誤重試。關鍵字輸入立即寫入網址，150ms 後請求，切換條件時取消舊請求。
- `page` 記錄目前批次；刷新／分享直接取得該批。越界批次回到末批，非正整數及空結果回到第一批。詳細頁 `returnTo` 保留批次與卡片錨點，sessionStorage 額外保存卡片在視窗中的座標。
- 累積超過 48 筆後使用 TanStack Virtual 的視窗捲動與動態列高度，只保留視窗附近及前後兩列。焦點所在列及鄰列保持掛載，Tab 可繼續依資料順序移動。支援 1／2／3 欄及放大字體。
- 圖片保留 96×96 空間；起始前三張優先，其餘靠近視窗 240px 才請求，完成後淡入，支援 reduced motion。缺圖及載入失敗各有替代內容。虛擬列表捲動時延後新圖片請求，停止 160ms 後恢復。
- 保留現有 CSV Repository 快取；未改寫讀取中的 Promise，也未加入資料庫或狀態管理套件。

## 前後量測

同一台本機，Node 24.21.0、Yarn 4.9.4、Next.js 15.4.6、正式建置與預設 CSV。Chromium viewport 1440×900；初始畫面等待控制項啟用與 network idle。HTML 大小為 HTTP 回應的未壓縮 UTF-8 bytes。修改前為 `08ec060`。

| 指標 | 修改前 | 修改後 |
| --- | ---: | ---: |
| 首次 `/pokemon` HTML | 14,328,614 bytes | 182,425 bytes |
| 初始卡片 DOM | 1,032 | 24 |
| 初始全部 DOM 節點 | 59,173 | 1,540 |
| 初始 `<img>` 節點 | 2,630 | 65 |
| 初始圖片請求（含屬性圖示等） | 48 | 24 |
| 單次觀察的 loadEventEnd | 1,120ms | 59ms |

HTML 約減少 98.7%。修改後連續載入六批、累積 144 筆，當時實際保留 **21 張卡片、1,370 個 DOM 節點**，捲回開頭可重新顯示原卡片。這是該視窗位置的觀察值；可見數隨高度、欄數與焦點列變化，並非固定總數。

時間為單次本機觀察，受快取與機器環境影響，不當作服務效能保證或測試時間門檻。正式建置的圖鑑首載 JS 由約 120kB 增至 132kB，主要增加虛擬化功能；HTML 與常駐 DOM 大幅減少。

## 行為驗收

- 批次端點：24 筆上限、全 1,032 筆排序及型態唯一性、完整總數、無相剋欄位、末批與越界。
- 無限捲動：自動追加、前一批、載入範圍、空結果、失敗重試、慢速舊查詢不覆蓋新查詢。
- 網址：搜尋、主副屬性、傳說條件、當前批次、刷新、分享、詳細頁刷新後返回與瀏覽器上一頁。
- 圖片：慢速載入時尺寸不變、首屏請求數受限、失敗提示與詳細頁連結可用。
- 虛擬化：六批資料時 DOM 上限、快速捲回、375px 與 20px 根字體下無橫向溢出及重疊、焦點保留、Tab 順序、虛擬區段詳細頁返回。
- 保留原有型態、倍率、首頁與手機導覽測試。

## 發現與修正

虛擬化接入時發現瀏覽器捲動錨定可能追隨頁尾，造成連續載入；同時，過於頻繁的位置還原會把快速捲回的畫面拉回來源位置。現在圖鑑掛載期間停用瀏覽器自動錨定，只有切換虛擬版面、前段插入、改變欄數及返回時還原，使用者操作會取消還原。快速捲回頂部也會更新網址，刷新時不會跳回先前批次。

正式版另發現點擊詳細頁後，尚未結束的捲動事件可能改寫來源錨點。現在導覽期間固定來源位置，返回掛載後才恢復追蹤；瀏覽器上一頁案例連續三次通過。

Firefox 在測試攔住圖片回應期間會對相同 URL 發出多次請求，因此以不同圖片來源計算首屏載入上限，並另外驗證遠處圖片尚未掛載。macOS WebKit 的連結焦點測試使用 Option＋Tab，符合 [Safari 的預設鍵盤操作](https://support.apple.com/en-sg/guide/safari/cpsh003/mac)。

開發服務與正式服務共用 `.next` 會互相覆寫資源，曾導致圖片請求卡住及模組載入錯誤。最後在 `/tmp` 的獨立專案副本建置並驗收，工作區原本的開發服務維持執行。測試未啟用自動重試或跳過案例。

## 剩餘邊界

- #16 的型態圖片索引問題仍獨立待辦；本次改善載入方式，不重新對應圖片。
- 深層返回只載入來源批次，較早資料透過「載入前 24 筆」取得。瀏覽器目前未掛載的虛擬卡片不參與頁內尋找，請使用圖鑑搜尋。
- CSV 資料仍在伺服器記憶體中；分批縮小的是卡片組裝、傳送與瀏覽器渲染，不是改成資料庫查詢。
