# 官方圖鑑補圖驗收

驗收日期：2026-09-26。來源為使用者指定的[台灣寶可夢官方圖鑑](https://tw.portal-pokemon.com/play/pokedex/)，延續 [#16 型態圖片對應](image-form-mapping.md) 的明確型態對照規則。

圖片保存於 `public/img`，檔名為 `三位圖鑑編號_formId.png`，並加入 `src/app/pokemon/lib/pokemonFormImages.json`。沒有覆寫既有圖片、增加 CSV 寶可夢資料或改變頁面載入方式；頁面仍由本機提供圖片，不會在執行時請求官方網站。

## 來源與型態確認

從官方圖鑑公開頁面的型態資料核對相同圖鑑編號、型態名稱、身高、體重及屬性，採官方指定的原始 PNG 網址下載。每張圖片的官方詳細頁、圖片 URL、中文名稱與型態、配對理由、圖片尺寸、檔案大小及 SHA-256 均記錄於 [pokemon-image-sources.json](../../data/pokemon-image-sources.json)。來源檔另外保留未提供專圖的型態及原因，供後續補圖時重查。

- 一般噴火龍、Mega X、Mega Y 各用自己的圖片；Mega X／Y 額外核對官方名稱後綴。
- 一般、伽勒爾與伽勒爾達摩模式的達摩狒狒分別對照；後兩者身高體重相同，依官方型態名稱與冰／冰火屬性區分。
- 南瓜精與南瓜怪人的官方身高體重分別是 0.4 m／5 kg、0.9 m／12.5 kg，精確對應 CSV 的 `Average Size`。
- CSV 的 `Minior Core Form` 未細分核心顏色，採官方「核心／紅色」圖片為代表，並在來源紀錄註明，不變更 CSV。
- 每張下載圖片皆核對 PNG 格式、尺寸、SHA-256 與型態對照，並以 Sharp 完整解碼；抽查 Mega X／Y、伽勒爾達摩模式與紅色核心原圖。

## 驗收

環境：Node.js 24.21.0，既有 Next.js 15.4.6、Vitest 與 Playwright。使用正式建置及自行啟動的 `127.0.0.1:3036` 服務。

| 檢查                                                                                                                                     | 結果                                       |
| ---------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 129 張原始 PNG 完整解碼、SHA-256 及對照檔核對                                                                                            | 通過                                       |
| `yarn build`（含型別與 lint）                                                                                                            | 通過                                       |
| `yarn test:unit`                                                                                                                         | 21 個檔案、68 tests 通過                   |
| 圖片測試局部 ESLint、TypeScript、Prettier                                                                                                | 通過                                       |
| `PLAYWRIGHT_BASE_URL=http://127.0.0.1:3036 yarn test:e2e tests/e2e/image-form-mapping.spec.ts tests/e2e/list-images.spec.ts --workers=1` | Chromium／Firefox／WebKit 共 45 tests 通過 |

圖片 E2E 以 10 種代表型態驗證列表與詳細頁使用相同專圖、實際解碼成功、能力值及型態網址保留；另驗證小智版甲賀忍蛙與特大南瓜怪人的缺圖提示、HTTP 請求失敗及既有延遲載入行為。單元保留缺檔、未知型態、檔案順序及三／四位編號邊界，增加新型態圖片彼此隔離與尺寸不混用的檢查。
