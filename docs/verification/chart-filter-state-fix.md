# #22 傳說切換保留散佈圖條件

日期：2026-09-26。

## 修正行為

- 同頁更新傳說條件時，仍有效的 X／Y 軸保持使用者選值。只有能力選項失效或兩軸衝突才回退到可用且不同的能力；僅有一項能力時兩軸共用該項。
- 主屬性以使用者關閉的屬性記錄偏好，並由目前資料推導可見選項。資料引用更新不重設篩選；暫時沒有樣本的屬性返回時仍沿用偏好，新出現的屬性預設顯示。
- 既有選取依穩定的編號及 `formId` 保留；資料中消失或被主屬性條件隱藏的樣本從結果清除。
- 能力軸的主動切換仍清空選取，沒有新增跨頁狀態保存。

## 頁面回歸

`tests/e2e/chart-filter-state.spec.ts` 以實際控制項與滑鼠框選驗收：

1. X 軸特攻、Y 軸速度、關閉火屬性後，往返切換排除傳說；兩軸與火屬性條件保持不變，框選結果仍符合條件。
2. 已選 Bulbasaur 與 Mewtwo 後排除傳說，不重新框選即可確認 Bulbasaur 留下、Mewtwo 與傳說詳細結果移除。
