## 整合驗證

- `yarn lint`、`yarn typecheck` 通過。
- `yarn test:unit`：24 檔、157 項通過；包含正式 1,032 列、125 列傳說與 fixture 相容性。
- 隔離正式建置成功，三瀏覽器完整圖鑑首次為 **336 通過、3 失敗**；失敗均為下述已修正的字型測試空白比較，證據 `test-results/regression-BoZobr/catalog.log`。
- 修正版字型案例在相同正式服務重跑三瀏覽器 **3／3 通過**，證據 `test-results/regression-Tx5HBD/catalog.log`。
- `yarn test:e2e --suite=averages` 另行隔離建置，三瀏覽器 **18／18 通過**，證據 `test-results/regression-XSoTJX/averages.log`。
- 合併上述最終結果，**357 個不同 E2E 案例均已通過**（336＋3＋18），不是宣稱首次完整命令零失敗。產品程式 72 個檔案已核對與完整圖鑑測試快照相同。
- 本輪新 UI 案例：徽章 6 項（108 組屬性／主題／瀏覽器測量）、標題 12 項、404 12 項、字型 3 項。

完整圖鑑測試首次使用的字型案例，將 CSS 變數及 computed font-family 直接以字串比較；Chromium 的逗號後空白造成誤判。實際 Geist 字族已載入，修正測試為比較正規化後的完整字族陣列，保留首選字族 loaded 斷言；產品碼不需變更。修正測試後定向重跑，其他測試仍以同一份正式建置完成。

已人工檢查暗色電屬性卡片與 320px 404 截圖，字型及返回按鈕顯示正常，手機 404 無水平溢出。標題驗證採 DOM 可存取角色，未實際操作讀屏軟體。
