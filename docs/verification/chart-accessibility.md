# #24 圖表鍵盤與觸控選取

日期：2026-09-26。

## 操作與範圍

散佈圖增加「搜尋並選取寶可夢」，使用英文名稱或圖鑑編號搜尋目前符合傳說及主屬性條件的樣本。候選最多顯示 12 筆，顯示總筆數及縮小範圍提示；空白輸入及無結果各有訊息。名稱搜尋不區分大小寫，編號可帶前置零。

每個候選提供原生按鈕及詳細頁連結，按鈕以 `aria-pressed` 表達選取狀態，焦點有可見外框。選取與取消沿用原有穩定型態 key、圖上的標記及選取結果清單，不新增第二份選取狀態。詳細頁使用 ViewModel 的型態網址，停用預取。

直條圖「比較能力」改為與 select 關聯的 label。滑鼠框選維持可用；觸控操作使用搜尋及原生按鈕，不攔截頁面捲動。跨頁選取保存及手機拖曳框選仍不在本票範圍內。

## 驗收案例

`tests/e2e/chart-accessibility.spec.ts` 涵蓋：

1. 完全用鍵盤到達搜尋欄，輸入 Mega Charizard X、選取，再開啟正確型態詳細頁，確認能力值可讀。沒有透過程式呼叫 focus 或滑鼠啟動。
2. 以 `006` 搜尋 Mega Charizard Y、選取及取消，隱藏火屬性後清單不再提供該型態。
3. 390×844 觸控視窗以真實 `tap` 操作搜尋、選取及開啟 Mega Charizard Y，確認型態網址與能力值。

macOS 的 WebKit 預設以 Option＋Tab 導覽原生按鈕及連結，因此該環境使用 `Alt+Tab`；其他瀏覽器與平台使用 `Tab`，均以 Enter 啟動。此差異已用獨立原生 HTML 實測，並符合 [Apple Safari 鍵盤快捷鍵說明](https://support.apple.com/en-az/guide/safari/cpsh003/mac)。測試沒有更改產品的焦點策略或跳過 WebKit。
